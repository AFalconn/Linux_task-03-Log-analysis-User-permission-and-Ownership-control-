# Screenshots

Save screenshots of the actual Linux Task 03 activity here.

## Naming convention

Use a numbered, descriptive filename that reflects the real task step, for example:

- `01-environment.png`
- `02-command-and-result.png`
- `03-verification.png`

These are examples only; rename them to match your assignment.

## Screenshot quality checklist

- Show the relevant command and its result in the same image when practical.
- Keep text readable and crop out unrelated windows.
- Capture genuine evidence from your own lab session.
- Redact credentials, tokens, private keys, personal information, and sensitive host details.
- Reference each screenshot from `docs/LAB_REPORT.md`.

Git does not track empty directories. This README keeps the folder in the repository until you add screenshots.
