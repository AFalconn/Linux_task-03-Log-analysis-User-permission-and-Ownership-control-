# Evidence and Verification

Use this folder for supporting text evidence or verification notes that do not fit naturally in `screenshots/` or the lab report.

Possible contents, if required and safe to share:
- A short verification summary.
- Sanitized command output.
- A checklist mapped to the assignment requirements.

Do not save credentials, private keys, personal data, or unnecessary system dumps here. Keep large or sensitive raw outputs out of a public repository.
